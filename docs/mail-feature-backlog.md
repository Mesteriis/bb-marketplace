# Бэклог возможностей почтового клиента в BB

Список из 100 возможностей для полноценного почтового клиента внутри BB — IDE для работы с ИИ-агентами. Номер — общий приоритет по всему списку (1 — самое ценное): ценность для владельца × соответствие идее «почта внутри агентной IDE» × трудоёмкость. Пункты разложены по группам, внутри группы идут по возрастанию номера.

Метки: `[уже есть]` — работает сейчас; `[следующий срез]` — решено делать следующим; `[кандидат]` — после него; `[позже]` — без срока. Трудоёмкость: S — дни, M — одна-две недели, L — больше. «Риск:» отмечает пункты, затрагивающие приватность или безопасность.

Метки сверены 2026-11-16 с тем, что вошло в срезы 3a–3f (см. `plugins/mail/CHANGELOG.md`). Срез 3d «доводка отправки» дал пункты 24, 33, 45, 55 и 61 (дизайн — `docs/superpowers/specs/2026-11-15-mail-slice-3d-sending-polish-design.md`). Срез 3e «разбор входящих» дал пункты 20, 25, 26, 41, 42, 44 и 73 (дизайн — `docs/superpowers/specs/2026-11-15-mail-slice-3e-inbox-triage-design.md`); срез 3f «агент и почта» дал пункты 22, 46, 47, 58, 59, 60, 66, 68, 69 и 90 (дизайн — `docs/superpowers/specs/2026-11-16-mail-slice-3f-agent-and-mail-design.md`); следующий срез пока не выбран.
