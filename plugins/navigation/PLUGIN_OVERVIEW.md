# Makosh Navigation

Customizable BB navigation with nested groups, icons, separators and a settings editor with autosave. Experimental SDK integration. One layout per installation.

With Makosh Sidebar, the native top header hosts **Сегодня / Проекты** tabs and a compact new-chat button. The plugins exchange whitelisted same-document events without imports or a hard dependency. Without Sidebar, or below 90 px of header space, the original new-chat control remains. Below 180 px the tabs use accessible icons. Custom navigation groups remain unchanged.
