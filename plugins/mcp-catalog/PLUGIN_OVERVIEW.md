## MCP Каталог

Страница «MCP Каталог» в боковой панели BB (иконка Plug): MCP-серверы поверх моста Agent Plugins. Три вкладки и кнопка «Обновить». Каталог сам ничего не запускает: серверы живут на мосту с его остановкой по простою и поиском инструментов по запросу.

**Стоящие.** Все серверы моста со статусом (работает, простаивает, нужно одобрение, нужен вход, ошибка) и числом инструментов. Действия: включить или выключить, одобрить, войти (открывает адрес http или https). Серверы, поставленные каталогом, можно удалить, обновить до принятой более новой версии из коллекции и изменить их переменные (заменить значение или очистить; только объявленные сервером переменные). Серверы из infra помечены «из infra» и отсюда не удаляются.

**Поиск.** Запрос в официальный реестр MCP (`registry.modelcontextprotocol.io`). Одна строка на сервер: по умолчанию последняя версия, другая выбирается в списке; источник (npm, PyPI, Docker, удалённый адрес), дата публикации, пометки «уже стоит», «в коллекции», «проверяется». «Проверить» запускает тред проверки выбранной версии в проекте маркетплейса (Claude Code, Sonnet, режим разрешений `auto`). Агент проверки пишет отчёт и черновик записи в своё рабочее дерево, ничего не коммитит.

**Коллекция.** Сверху — проверки. Когда тред закончил работу, доступны «Принять» и «Отклонить». «Принять» — согласие владельца: каталог сверяет `server.json` с записью реестра для проверенной версии, коммитит запись на ветке проверки, сливает её в `main` и делает push. Новая версия уже принятого сервера заменяет его строку в индексе. «Отклонить» только записывает отказ; тред и рабочее дерево владелец архивирует сам. Ниже — проверенные серверы с выжимкой отчёта и кнопкой «Поставить».

**Установка.** Ставить и обновлять можно только запись, которую принял этот каталог и чей коммит принятия есть в `origin/main`; иначе «запись не принята в этом каталоге». Коллекция читается только из `origin/main`. Форма перечисляет объявленные сервером переменные: секреты вводятся в полях-паролях, заданный секрет показан словом «задано», значения в интерфейс не возвращаются. Обязательная переменная должна быть задана; несекретная, оставленная пустой, получает значение по умолчанию сервера. Аргументы пакета передаются только готовые; пакет с обязательным аргументом без готового значения не ставится. Установка пишет локальный пакет Agent Plugins и файл ключей (права 0600) в данных плагина и просит одобрения в мосту.

**Настройки.** Рабочая копия репозитория маркетплейса (`marketplaceRepoPath`) и проект маркетплейса в BB для тредов проверки (`marketplaceProjectId`), по умолчанию пустые. Пока они не заданы, страница показывает, что задать, и команду `bb plugin config <id> set <ключ> <значение>`; действия, которым нужна настройка, выключены.
