## Task 1: Список «+ Панель» собирается только когда нужен

1. `contentSections()` не вызывается при отрисовке, пока окно выбора закрыто.
   Заголовок, страница и окно выбора тайла получают разделы только при
   открытии окна выбора: функция-поставщик или вычисление внутри открытого
   окна.
2. Пока окно выбора открыто, разделы обновляются по мере изменения данных,
   как сейчас.
3. Отрисовки заголовка и страницы не запускаются изменениями списка тредов,
   которые их не касаются:
   - `ThreadDirectory.set` с тем же содержимым не меняет версию;
   - если заголовку или странице нужно только название или статус открытых
     тредов, они подписываются на это.

   Если это требует перестройки, ограничиться первым пунктом и записать вывод
   в отчёт.
4. Тесты:
   - при закрытом окне выбора `contentSections` не вызывается ни при
     отрисовке, ни при смене версии (счётчик вызовов);
   - при открытии вызывается, и разделы те же, что раньше;
   - одинаковый повторный `threads.set` не увеличивает версию.
5. Измерение. Микробенчмарк в тестах или скрипт:
   - сколько стоит `contentSections()` на 50 тредах и всех провайдерах;
   - сколько раз она вызывается за 100 обновлений тредов до и после.

   Записать числа в отчёт.

## Task 2: Переключатель «Тайловое пространство»

1. Сервер объявляет настройку `tileSpace` через `bb.settings.define`, как
   `homeRedirect`:
   - булева, по умолчанию включена;
   - подпись «Тайловое пространство»;
   - описание: «Страница Чертога с тайлами. Выключите, чтобы Чертог не
     работал в окне.»
2. Выключенная настройка:
   - не монтирует слой живых панелей, наложение окна, слушатель
     `chertog.open.v1` и подписки на треды;
   - запрос `chertog.open.v1` остаётся без ответа (`accepted: false`), и
     Makosh Sidebar открывает тред штатно;
   - верхняя полоса BB на маршруте Чертога показывает только название
     «Чертог», без кнопок;
   - страница показывает одну строку: тайловое пространство выключено в
     настройках Чертога, и путь к настройке;
   - перенаправление «Домой → Чертог» не срабатывает, даже если включено;
   - команды Чертога для выбранного тайла не действуют.
3. Без перезагрузки:
   - включение и выключение срабатывает, как только BB доставит новое
     значение настройки;
   - сохранённые раскладки не трогаются и возвращаются при включении.
4. Пока значения настроек не доставлены, ничего не монтируется. Отсутствие
   ключа читается как включено, чтобы не сломать существующие установки.
5. Тесты:
   - чтение настройки (не доставлено, нет ключа, вкл, выкл);
   - выключенная — нет ответа на `chertog.open.v1`, нет перенаправления;
   - пустой заголовок, строка на странице;
   - переключение туда и обратно восстанавливает раскладку.
6. Документация:
   - README и PLUGIN_OVERVIEW (в пределах 4000 символов);
   - при изменении описания — `bb.description` и запись `marketplace.json`.
