## Воспроизведение и фиксация результата

Подготовить [изолированный веб-стенд](e2e-stand.md), включить `acceptanceFixture`, добавить Terminals, тестовую среду с `sample.md` в двух ревизиях и тестовый тред с терминалом. Точные имена целей и аргументы запуска заданы в [сквозной пробе B](../tests/adapters/app/stage-b-probe.mjs). Из каталога плагина:

```sh
npm run check
npm run build
node tests/adapters/app/stage-b-probe.mjs "$STAND_URL" "$PLAYWRIGHT_TOOLS_DIR" "$CHROMIUM"
```

На срезе `59651883` в отдельной копии пакета `npm run check` завершился успешно: typecheck и 1058 тестов в 57 файлах. `npm run build` собрал серверный и клиентский бандлы с предупреждением о версиях SDK (в пакете 0.6.157, в CLI 0.6.132). При составлении таблицы сквозную пробу повторно не запускали.

Для каждого прогона записать SHA, версии BB и провайдера, тип стенда, действие, сравнимые обезличенные ID и счётчики до/после, результат команды и первый несовпавший шаг. Для Zoom записать наблюдения второго клиента. Для экранов — масштаб и фактическую рабочую область. Приглашения, переписку и содержимое реальных терминалов в журнал не включать.
