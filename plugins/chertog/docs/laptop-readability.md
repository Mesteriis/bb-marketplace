# Чертог на экране ноутбука

В раскладке из четырёх тайлов при 1280×800 две правые вкладки на исходной сборке получали по 0 CSS px для текста. После исправления под подписи остаются 70 и 69 px, крестики целиком видны. Меню четвёртого тайла принимает нажатия над соседней живой панелью. На ширине страницы 640 CSS px сообщение «Не сохранено» и кнопка «Сохранить ещё раз» помещаются рядом с переключателем.

## Условия и матрица

22 ноября 2026 года. Исходная версия — `33c96465`. Веб-стенд запущен по [инструкции](e2e-stand.md) с отдельными HOME, каталогом данных и портами. На стенде включена настройка `acceptanceFixture`. В Chromium открыта страница `/plugins/chertog/home`. Через «Добавить панель» открывались разные экземпляры тестовой страницы. В диалоге закрытия выбран пункт «Скрыть панель». Один документ браузера сохранялся на время прогона, чтобы скрытые iframe оставались живыми.

Каждый снимок ниже содержит три кадра сверху вниз — два, три и четыре **видимых** тайла, плюс скрытые панели. DPR задаёт плотность пикселей. Две последние строки дополнительно уменьшают доступную CSS-область вдвое и воспроизводят переразметку страницы при увеличении до 200%.

В каждой из 18 конфигураций открыты переключатель раскладок, список скрытых, диалог закрытия, выбор содержимого и меню каждого видимого тайла. Для всех 54 открытий меню проверены границы рабочей области и попадание мышью в оба пункта у левого края, посередине и у правого края. Для 36 открытий списков раскладок и скрытых панелей проверены их левая и правая границы. Boot ID живых iframe сохранились во всех 18 конфигурациях. После стабилизации раскладки горизонтальное переполнение документа — 0 CSS px. Среди видимых кнопок этих поверхностей не обнаружено целей меньше 24×24 CSS px или выхода за боковые границы окна. Отдельно проверены границы крестиков относительно полосы вкладок. Измерения относятся к обвязке Чертога. Внутренний диагностический текст iframe-фикстуры в узком тайле переносится или прокручивается самой страницей.

## Цвет и границы проверки

Обвязка использует семантические токены BB. В светлой теме стенда измеренный контраст текста кнопки «Добавить панель» и пункта меню составил 12,63:1, активной строки раскладки — 10,22:1, статуса «Не сохранено» — 8,06:1. Измерения сделаны по вычисленным браузером цветам текста и фона. Другие темы BB в этом прогоне не проверялись.
