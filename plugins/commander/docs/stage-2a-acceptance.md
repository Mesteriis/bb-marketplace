# Приёмка Commander S18

База замера до оптимизации — `cfc7fad521b1b7c9953c56ba23ab0840cb2642c2`.
Замеры 28 ноября 2026 года на MacBook Pro Mac17,7, Apple M5 Max, 64 ГБ,
macOS 27.0.1 (26A434), arm64, Node.js 24.20.0. Замеры на машине под
обычной текущей нагрузкой, без контролируемого холодного дискового кеша.
Тестовые данные описаны в [README фикстур](../tests/fixtures/stage-2/README.md).

## Стенд и методика

- Backend-харнесс активирует `server.ts`, вызывает зарегистрированные RPC
  с проверкой входных и выходных схем и использует SQLite и штатный
  `host-fs` над настоящими файлами. Процесс Node включает сервер и адаптер
  хоста. Приведён RSS всего этого процесса. Для копирования максимум
  накопительный с запуска процесса на один размер данных, включая
  валидацию base64 и предыдущие операции прогона.
- Для SFTP заменена граница RPC Remote Hub. Мок читает и пишет реальные
  файлы по смещениям в отдельном каталоге, включая передачу base64 через
  адаптер Commander. Сеть, SSH и отдельный процесс Remote Hub в замер
  не входят.
- Playwright запускает отдельный headless Chromium 156.0.8078.4, 1440×900.
  Загружается настоящий `app.tsx` со штатным листингом через loopback HTTP.
  Заглушка SDK подключает экран и транспорт. Отсчёт от навигации до двух
  кадров после появления первой полезной строки. За это время приложение
  получает все 100 страниц по 1000 записей. Снимок и логи в треде S18.
- Поиск измерен от `scan_start` до получения состояния `done` у
  `scan_get`. Запрос `item-099999.bin` дал одно точное совпадение.
- Копирование и распаковка измерены от `plan_run` до терминального
  состояния `job_get`. SHA-256 источника и результата сверялись отдельно.
  Отмену подавали после появления непустого временного файла, поиск
  отменяли через 50 мс после старта. Приведено время от команды отмены
  до наблюдения терминального состояния. В прогонах отмены копии и
  распаковки проверялось отсутствие временного и целевого файлов.
- RSS сервера — `process.resourceUsage().maxRSS`, helper — максимум
  выборок `ps` с интервалом 25 мс. Короткие пики helper между выборками
  могли остаться за пределами замера. Время опроса задания включает до
  одного интервала опроса в 15 мс плюс задержку планировщика.

### Цели для следующего прогона

Начальные пределы для того же харнесса получены округлением вверх
наблюдавшихся значений с запасом около 25%. Для первой отрисовки
использован более медленный прогон. Для отмены принят общий предел
200 мс по самому медленному наблюдению 149 мс. Сравнение имеет смысл
при сопоставимой нагрузке и размерах. Это цели повторной проверки,
а не пределы для живой сети или обещания на других машинах.

| Операция | Цель по времени | Цель по RSS сервера |
|---|---:|---:|
| Первая полезная отрисовка | ≤ 40 с | ≤ 340 МиБ |
| Поиск по 100 000 | ≤ 20 с | ≤ 270 МиБ |
| Local → local, 4 ГиБ / 1 ГиБ | ≤ 0,7 с / 1,1 с | ≤ 195 МиБ |
| Local → SFTP-мок, 4 ГиБ / 1 ГиБ | ≤ 4,2 с / 2,7 с | ≤ 500 МиБ |
| SFTP-мок → local, 4 ГиБ / 1 ГиБ | ≤ 43 с / 27 с | ≤ 575 МиБ |
| Распаковка ZIP / TAR | ≤ 23 с / 29 с | ≤ 665 / 725 МиБ |

Цель по наблюдаемому RSS helper для обоих форматов — ≤ 16 МиБ.

## Известные нестабильности

Три последовательных запуска полного `npm run check` с текущей
конфигурацией `unit` + `heavy` завершились кодом 0. Проект `heavy`
сохранён с лимитом 30 секунд и последовательным запуском его файлов.

| Прогон | Load average перед стартом (1/5/15 мин) | Vitest | Результат |
|---|---:|---:|---|
| 1 | 9,78 / 13,20 / 12,72 | 26,05 с | 63 файла, 1173 прошли, 2 пропущены |
| 2 | 16,65 / 14,46 / 13,20 | 18,64 с | 63 файла, 1173 прошли, 2 пропущены |
| 3 | 16,13 / 14,50 / 13,25 | 14,88 с | 63 файла, 1173 прошли, 2 пропущены |

`npm run build` завершился кодом 0. Инструмент сборки сообщил, что
Commander закреплён на Plugin SDK 0.6.132, а установленный BB предлагает 0.6.157.
После изменений генератора отдельно прошёл ещё один `npm run check` с тем же
числом тестов (`check-final.log`). Готовый arm64-модуль `better-sqlite3`
12.11.1 взят из ранее подготовленного изолированного стенда. Его загрузка и
запрос `SELECT 1` проверены на Node.js 24.20.0.
