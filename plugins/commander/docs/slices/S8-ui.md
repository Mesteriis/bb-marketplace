`docs/design/v2/` (HTML-артборды и снимки):

`--destructive`), без собственной палитры. Иконки — Lucide через иконки BB
(`icon.tsx`), не SVG-файлы артборда.

## Цель

Страница `slots.navPanel` «Commander» и компактная вкладка у треда
(`slots.experimental_tab`) поверх RPC S7: две панели, клавиатура в традициях
Commander, очередь, диалог конфликта, план агента.

## Принятые пути

`app.tsx`, `app.test.tsx`, `src/ui/**`.

Исключение владения: S8 синхронно обновляет описание видимого поведения в
`bb.description` (`package.json`), первой строке `PLUGIN_OVERVIEW.md` и
записи `commander` в `marketplace.json` (только эти поля; затем
`check-manifests`). `src/ui/index.ts` (заглушка S0) переходит к S8.

## Контракт

- `src/ui` получает данные и колбэки через props (правило каркаса); вызовы
  `useRpc`/`useRealtime` — только в `app.tsx`.
- Состояние панелей (вкладки, путь, выделение, сортировка, фильтр, позиция) —
  через RPC `ui_state_get`/`ui_state_set` из S7 (схема `UiState` в
  `src/core/wire/rpc.ts`, владеет S7); запись с debounce; remount не теряет
  состояния.
- Клавиатура: только `onKeyDown` на корне страницы; ни одного слушателя на
  `window`/`document`. F3 (`experimental_openFilePreview({kind:"host"})`),
  F4 (тот же preview/редактор BB), F5, F6, F7, F8, Tab, Insert/Space,
  `+`/`-`/`*` маски, Shift+F6 переименование; альтернативы macOS (⌘↑ вверх,
  ⌘⌫ удалить, ⌘C/⌘V как F5) и переназначение — в настройках.
- Виртуализация списка (без DOM на каждую из 10 000 строк).
- Рядом с путём: endpoint, машина, провайдер, read-only.
- Очередь: компактная полоса с раскрытием; инициатор (владелец/тред),
  endpoint, этап, отмена.
- Диалог конфликта: причина, оба отпечатка, действия и «для остальных с той
  же причиной».
- Терминал: `useSdk().terminals.create({scope:{kind:"host_path", hostId, cwd}})`
  + `experimental_openTerminal` только для local endpoint.
- Токены и компоненты BB (`components/ui`), русский интерфейс со строками в
  одном модуле.

## Раскладка (из варианта 2)

- Шапка 44 px: заголовок, подсказка «Tab — другая панель», справа «Поменять»
  и «Сравнить каталоги».
- Сетка: две панели поровну + инспектор 320 px справа (сворачивается; при
  ширине < 1200 px — сворачивается сам, очередь остаётся иконкой со счётчиком).
- Панель: строка источника (иконка машины, endpoint, провайдер, режим
  доступа; активная панель — акцентный цвет и рамка адресной строки), вкладки
  справа от неё, адресная строка-крошки с поиском, таблица Имя/Размер/Изменён
  (Права — опциональная колонка), строка итога «N из M выделено · размер».
- Выделение — цвет `--warning` и жирное имя; курсор — фон строки; у неактивной
  панели курсор — только рамка.
- Инспектор: «Очередь» со счётчиком; карточка job: заголовок, полоса
  прогресса, состояние цветом (ждёт решения / ждёт разрешения / выполняется /
  готово / ошибка), инициатор (Вы или тред), деталь, действия по состоянию
  («Сравнить и решить»/«Пропустить», «Посмотреть план», «Пауза» только при
  capability, «Отменить»); внизу «Выделено слева»: число, размер, назначение.
- Нижняя панель действий: кнопки с подписью и клавишей (F3–F8), справа
  «Терминал здесь».
- Диалог конфликта: заголовок-причина, строка задания, две колонки
  «Копируемый / В назначении» с машиной, размером, датой (и «новее на …»),
  действия Заменить ⏎ / Пропустить S / Сохранить оба R / Сравнить содержимое,
  флажок «так же для остальных с той же причиной», строка про атомарность
  замены по capabilities, «Отменить задание Esc».
- План агента: тред-инициатор, время фиксации и результат `revalidate`,
  шаги (источник, назначение и выданный доступ, маршрут и проверка, удаление
  источника и обратимость), предупреждение «изменение выделения не меняет
  план», «Разрешить и запустить» / «Отклонить» / «Открыть тред».
- Вкладка у треда: endpoint окружения треда, переключатель двух источников
  вместо двух панелей, адрес, список Имя/Размер, мини-очередь (активный job,
  конфликт с «Решить»), действия «Копировать в…», «Просмотр», «Терминал»,
  кнопка открытия полной страницы.

## Проверки

- `app.test.tsx` (jsdom): F5 внутри корня открывает план копирования; F5 в
  `<input>` вне корня — нет и `defaultPrevented === false` (регрессия
  спайка DotDir); Tab меняет активную панель; remount сохраняет путь и
  выделение.
- 10 000 записей: в DOM ≤ 200 строк.
- Иконка `navPanel` `"Folders"`: при первой установке в тестовый BB
  проверить, что она отрисовывается в навигации (неизвестное имя BB
  молча заменяет иконкой branding — это провал проверки).
- Браузер (тестовый BB, headless): ноутбук 1440×900 и монитор 2560×1440,
  масштаб 125%; скриншоты страницы, очереди, конфликта; фокус виден.
- Accessibility: таблица с ролями `grid`/`row`, подписи кнопок F-панели.
