# BB Chat Dock

Страница **ChatGPT** в BB с chatgpt.com внутри. Сайт показывает собственное
окно плагина, приклеенное к области страницы: оно стоит ровно на ней, двигается
вместе с окном BB и держит вход в ChatGPT между запусками. Справа страница
показывает текст, который вы выделили в треде, и передаёт его в это окно. Окно
показывает тот же текст и беседу-адресата; в черновик текст попадает только
после вашего нажатия «Вставить в черновик» в самом окне. Сообщение
отправляете вы. Плагин не читает переписку, черновики, cookies и не обращается
к API ChatGPT.

Состояние: экспериментальный. Требует macOS 14+, BB 0.50+, SDK 0.6.157+ и
Xcode или Command Line Tools: окно собирается на вашем Mac при первом
открытии. Вставка проверена на синтетической странице в WebKit и Chromium, не
на настоящем chatgpt.com.

## Как пользоваться

1. Выделите текст в сообщении ассистента и выберите в меню выделения
   «Вставить в ChatGPT…». Либо введите текст на странице ChatGPT сами.
2. На странице ChatGPT в навигации BB проверьте и при необходимости
   отредактируйте текст.
3. ChatGPT открывается в левой части страницы сам (если нет — «Открыть
   ChatGPT»). Войдите в аккаунт один раз и откройте нужную беседу.
4. Нажмите «Передать в ChatGPT». Внизу окна ChatGPT появится панель с точным
   текстом, источником и адресатом.
5. Нажмите в окне «Вставить в черновик», «Скопировать» или «Отмена».

«Скопировать контекст» на странице BB кладёт текст в буфер обмена без окна.

## Окно

- Только `https://chatgpt.com` и страницы входа (OpenAI, Google, Apple,
  Microsoft). Ссылка на другой сайт открывается в браузере по умолчанию.
- Нет адресной строки, кнопок навигации, кнопок и рамки окна, нет значка в
  Dock. Окно занимает область страницы, которую та отводит под ChatGPT,
  следует за окном BB при перемещении и изменении размера и стоит прямо над
  ним. Пока страница скрыта, окно BB свёрнуто или на другом рабочем столе,
  окно ChatGPT скрыто; данные и черновик в нём остаются. ⌘W закрывает его.
- Окно находит окно BB по его положению и размеру через список окон macOS,
  без прав Accessibility, и только среди окон приложения, которое сейчас
  впереди. Область не может выходить за видимую часть страницы. Если
  страница сообщила место, когда впереди другое приложение, окно ждёт, пока
  вперёд выйдет окно BB. Предполагается, что панели браузера стоят сверху и
  слева от страницы, как в BB Desktop, Chrome и Safari.
- Всплывающие меню и диалоги BB над этой областью окажутся под окном ChatGPT.
- Вход хранится в постоянном хранилище сайта окна и переживает закрытие
  окна, перезапуск плагина и BB.
- Своё хранилище сайта (`io.github.mesteriis.bb-chat-dock.window`), отдельное
  от Browser в BB. Инструменты агентов BB (`bb browser`) это окно не видят.
  Web Inspector отключён.
- Окно не открывает сетевых портов и слушает только процесс плагина, который
  его запустил. Отключение, перезагрузка или удаление плагина закрывает окно.
- Вход через Google или Apple во встроенном WebKit может быть заблокирован
  провайдером входа; вход по почте и паролю работает как обычно.

## Что гарантирует вставка

- Только `https://chatgpt.com`, основной документ окна, существующая беседа
  (`/c/<id>` или `/g/<проект>/c/<id>`). Новый чат и страница входа не
  подходят: остаётся «Скопировать».
- Беседа выбирается, когда текст приходит в окно. Любой переход страницы
  после этого, даже с возвратом на тот же адрес, перезагрузка или пропажа поля
  ввода отменяют вставку: текст не попадает никуда. «Выбрать открытую беседу»
  выбирает заново.
- Адрес проверяется в самой странице в том же шаге, что и запись, после того
  как поле ввода получило фокус.
- Одна запись за раз; повторное нажатие не дублирует текст, плагин не
  повторяет вставку сам. Пока запись не завершилась, новый текст из BB не
  принимается.
- Плагин не читает черновик, поэтому пишет «Текст передан в поле ввода», а не
  «Вставлено». Если страница не ответила — «Результат неизвестен».
- Клавиша Enter не нажимается, сообщение не отправляется.

## Чего плагин не делает и от чего не защищает

- BB узнаёт об окне только состояние: открыто ли оно, ждёт ли текст, чем
  закончилась последняя передача. Ни текста страницы, ни адреса беседы.
- Агенты BB могут вызвать RPC плагина (`open`, `attach`, `propose`,
  `status`): открыть окно, показать в его панели текст, передвинуть окно в
  пределах страницы BB, которая впереди, или скрыть его до следующего отчёта
  страницы (она повторяет своё место каждые 2 секунды). Поставить окно над
  чужим приложением или за пределы страницы `attach` не может. Вставить
  текст может только ваше нажатие в окне. Читать страницу через плагин
  нельзя.
- Программы с полными правами в macOS (средства автоматизации интерфейса,
  Accessibility) могут видеть и нажимать окно, как любое другое. От них плагин
  не защищает.
- Не хранит текст: он живёт в памяти окна BB до передачи, очистки, отключения
  плагина или перезапуска BB. `bb plugin reload` с той же сборкой не
  перезапускает интерфейс уже открытого окна BB. В журналы и адреса текст не
  попадает.

## Установка в тестовый BB

```sh
cd plugins/chat-dock
npm install
npm run check
bb plugin build
bb plugin install .
```

Отключить: `bb plugin disable chat-dock`. Удалить: `bb plugin remove chat-dock`.
Собранное окно лежит в каталоге данных плагина на хосте; вход в ChatGPT
хранится в данных WebKit для `io.github.mesteriis.bb-chat-dock.window`.

## Разработка

Исходник окна — `native/ChatDockWindow.swift`. После правки выполните
`node scripts/embed-native.mjs`: хост-часть плагина везёт исходник с собой и
собирает окно сама (`xcrun swiftc`, локальная подпись). Тест сверяет копию с
файлом. Команды `test-*` и загрузка синтетической страницы есть только в
сборке с `-D CHAT_DOCK_TEST`.

## Ограничения

- Источник выделенного текста один: сообщение ассистента в треде. Для diff и
  логов BB не даёт плагину выделение; такой текст можно ввести вручную.
- Окно открывается на том Mac, где работает сервер BB.
- Поле ввода ChatGPT ищется по `#prompt-textarea`. Если сайт изменит
  разметку, вставка откажет и предложит копирование.
