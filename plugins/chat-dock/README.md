# BB Chat Dock

Страница **ChatGPT** в BB: показывает текст, который вы выделили в треде, и
передаёт его в ChatGPT по вашему действию. Сообщение отправляете только вы.
Плагин не читает переписку, черновики, cookies и не обращается к API ChatGPT.

Состояние: экспериментальный. Проверен на BB Desktop 0.50.1, SDK 0.6.157,
macOS на Apple Silicon. Автовставка проверена только на тестовой странице, не
на настоящем chatgpt.com.

## Два режима

**Ручная вставка (по умолчанию).** Выделите текст в сообщении ассистента,
выберите в меню выделения «Вставить в ChatGPT…», откройте страницу ChatGPT в
навигации BB. Там точный текст, его источник и поле для правки. «Скопировать
контекст» кладёт текст в буфер обмена; дальше вы сами вставляете его в
ChatGPT, где бы он у вас ни был открыт.

**Встроенный ChatGPT (включаете сами).** На странице плагина нажмите «Я
понимаю риск: включить встроенный режим». После этого на вкладках Browser с
`https://chatgpt.com` рядом с адресной строкой появляется «Вставить в
ChatGPT…». Нажатие выбирает беседу, открытую во вкладке, и показывает текст и
адресата. «Вставить в черновик» добавляет текст в конец черновика этой беседы.

### Почему встроенный режим выключен по умолчанию

У встроенного Browser один общий вход на все вкладки. Штатные инструменты
агентов (`bb browser create`, `acquire`, `capture`) открывают вкладки с этим
входом, управляют ими и снимают с них изображение. Если вы вошли в ChatGPT
внутри BB, агенты на этом компьютере технически могут читать вашу переписку.
Плагин не может это отключить. Включайте встроенный режим, только если это
для вас приемлемо.

## Что гарантирует автовставка

- Работает только на `https://chatgpt.com`, в основном документе вкладки, в
  существующей беседе (`/c/<id>` или `/g/<проект>/c/<id>`). Новый чат,
  страница входа и другие сайты отклоняются.
- Беседа выбирается в момент открытия панели. Смена беседы, переход,
  перезагрузка страницы или пропажа поля ввода отменяют вставку: текст не
  попадает никуда, в буфер обмена ничего не пишется.
- Адрес проверяется в самой странице в том же шаге, что и запись.
- Разрешение одноразовое: двойной клик не дублирует текст. Плагин не
  повторяет вставку сам.
- Плагин не читает черновик, поэтому пишет «Текст передан в поле ввода», а не
  «Вставлено». Если страница не ответила, он пишет «Результат неизвестен».
- Клавиша Enter не нажимается, сообщение не отправляется.

При любом отказе остаётся «Скопировать контекст».

## Чего плагин не делает

- Не даёт агентам ни одной команды: нет RPC, CLI, инструментов, настроек.
- Не хранит текст: он живёт в памяти окна до передачи, очистки, отключения или
  перезагрузки плагина. В журналы и адреса он не попадает.
- Не защищает от программ с полными правами в системе и от самого BB.

## Установка в тестовый BB

```sh
cd plugins/chat-dock
npm install
npm run check
npm run build
bb plugin install .
```

Отключить: `bb plugin disable chat-dock`. Удалить: `bb plugin remove chat-dock`.
Выбор режима хранится в локальном хранилище окна BB под ключом
`bb-chat-dock:embedded-mode:v1`; «Выключить встроенный режим» его удаляет.

## Ограничения

- Источник выделенного текста один: сообщение ассистента в треде. Для diff и
  логов BB не даёт плагину выделение; такой текст можно ввести в поле вручную.
- Автовставка есть только в BB Desktop: в веб-клиенте BB доступа к странице
  вкладки нет, остаётся копирование.
- «Открыть chatgpt.com в BB» следует настройке BB: встроенный Browser или
  системный браузер.
- Поле ввода ChatGPT ищется по `#prompt-textarea`. Если сайт изменит
  разметку, автовставка откажет и предложит копирование.
