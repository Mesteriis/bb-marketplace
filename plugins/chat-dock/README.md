# BB Chat Dock

Вкладка **ChatGPT** в навигации BB: в ней открыт chatgpt.com. Вы входите один
раз и ведёте диалог прямо во вкладке. Больше плагин ничего не делает: не
читает переписку, не вставляет текст, не обращается к API ChatGPT.

Состояние: экспериментальный. Требует macOS 14+, BB Desktop 0.50+, SDK
0.6.157+ и Xcode или Command Line Tools: окно собирается на вашем Mac при
первом открытии вкладки (до минуты).

## Как это устроено

chatgpt.com запрещает показывать себя внутри чужих страниц
(`frame-ancestors 'self'`), поэтому вкладка не может содержать его как
фрейм. Плагин запускает собственное окно ChatGPT без рамки, адресной строки,
кнопок и значка в Dock и кладёт его точно на вкладку.

- Окно двигается и меняет размер вместе с окном BB, стоит прямо над ним и
  прячется, когда вкладка закрыта, окно BB свёрнуто или на другом рабочем
  столе.
- Только `https://chatgpt.com` и страницы входа (OpenAI, Google, Apple,
  Microsoft). Ссылка на другой сайт открывается в браузере по умолчанию.
- Вход хранится в постоянном хранилище сайта окна
  (`io.github.mesteriis.bb-chat-dock.window`) и переживает закрытие окна,
  перезапуск плагина и BB. Оно отделено от Browser в BB; инструменты агентов
  BB (`bb browser`) его не видят. Web Inspector отключён.
- ⌘W закрывает окно; во вкладке появится «Открыть ChatGPT».
- Окно встаёт только на окно BB Desktop (`dev.bb.desktop`), когда он
  впереди, и никогда не выходит за его границы. В веб-интерфейсе BB в
  браузере вкладка окно не показывает.
- Окно не открывает сетевых портов и слушает только процесс плагина, который
  его запустил. Отключение, перезагрузка или удаление плагина закрывает его.

## Ограничения

- Всплывающие меню и диалоги BB над вкладкой окажутся под окном ChatGPT.
- Предполагается, что панели BB стоят сверху и слева от содержимого вкладки.
- Вход через Google или Apple во встроенном WebKit может быть заблокирован
  провайдером входа; вход по почте и паролю работает как обычно.
- Агенты BB могут вызвать RPC плагина (`open`, `attach`, `status`): открыть
  окно, сдвинуть его в пределах окна BB или скрыть до следующего отчёта
  вкладки (она повторяет своё место каждые 2 секунды). Читать или менять
  страницу ChatGPT через плагин нельзя. Программы с полными правами в macOS
  (автоматизация интерфейса) видят окно, как любое другое.

## Установка в тестовый BB

```sh
cd plugins/chat-dock
npm install
npm run check
bb plugin build
bb plugin install .
```

Отключить: `bb plugin disable chat-dock`. Удалить: `bb plugin remove chat-dock`.

## Разработка

Исходник окна — `native/ChatDockWindow.swift`. После правки выполните
`node scripts/embed-native.mjs`: хост-часть плагина везёт исходник с собой и
собирает окно сама (`xcrun swiftc`, локальная подпись). Тест сверяет копию с
файлом. Команды `test-*` есть только в сборке с `-D CHAT_DOCK_TEST`.
