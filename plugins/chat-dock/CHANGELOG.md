# Changelog

## Unreleased

- ChatGPT is now part of the ChatGPT page: the window has no frame or Dock icon, sits on the page's area, follows BB's window, hides while the page is hidden or BB is minimized, and keeps the sign-in. Fixed: the window failed to open on a second call ("host call context is no longer active").

The text is handed to the window and inserted after the user's press there. The Browser toolbar control and the embedded-mode switch are gone.
- First version: a ChatGPT page with a preview of text selected in an assistant message and an explicit copy; an opt-in embedded mode that appended the text to the draft of the conversation open in a Browser tab on chatgpt.com.
