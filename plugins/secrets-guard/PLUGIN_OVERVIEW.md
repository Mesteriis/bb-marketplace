## Что делает

Добавляет замок рядом с кнопкой отправки в поле ввода треда. Нажатие открывает окно, где охрана защищённых файлов Claude Code открывается на 10, 30 или 60 минут. Бессрочного открытия нет.

В окне одна строка: слева «Кому» — три сегмента охвата («Этот чат», «С субтредами», «Глобально»), справа «Открыть на» — три срока. Нажатие на срок сразу открывает охрану с выбранным охватом. Сегменты работают как радиогруппа: стрелки переключают охват с клавиатуры.

Пока охрана открыта, сверху видно «Открыто ещё N мин» и охват, рядом кнопка «Закрыть», под ними полоса остатка — доля от 60 минут. Сроки в этом состоянии подписаны «Продлить на» и заменяют срок. Замок у поля ввода становится подсвеченной плашкой с остатком, например «24 м».

Замок открывает собственное окно плагина прямо над кнопкой: по ширине содержимого, по правому краю кнопки. Оно закрывается по Escape, по нажатию вне его и по повторному нажатию на замок.

Строка «Секреты…» в меню «+» открывает те же элементы в окне BB на всю ширину поля ввода; это же путь в компактной раскладке, где замка у поля ввода нет. В узком окне сроки переходят под охват, а подпись остаётся только у выбранного сегмента охвата.

## Как это устроено

Плагин пишет общий файл-отметку, который читает хук охраны Claude Code на том же Mac. Сети между хуком и плагином нет. Фраза владельца «открой секреты» и «закрой секреты» продолжает работать и пишет ту же отметку; запись идёт под файлом-замком и через временный файл.

Для охвата «с субтредами» плагин записывает каждого потомка и обновляет записи, когда тред создаётся, архивируется, удаляется или меняет родителя. Если список субтредов получить не удалось, их записи снимаются до следующей удачной сверки; корневой чат остаётся открыт.

## Настройка

Настраивать ничего не нужно: хук охраны Claude Code сам публикует, где лежит его отметка, в файле-указателе `~/.claude/hooks/guard-location.json`, и плагин читает указатель при каждом обращении. Пока хук указатель не создал, замок неактивен; достаточно запустить любой тред Claude Code.

Поле «Файл отметки охраны» в настройках плагина необязательное. Заполненное, оно переопределяет путь из указателя. Если каталог файла недоступен для записи, замок неактивен, а охрана остаётся закрытой. При смене пути плагин сначала закрывает всё, что открыто в прежнем файле.

## Ограничения

- Работает только для тредов Claude Code на машине, где запущен сервер BB. У других провайдеров хука охраны нет.
- Для треда на удалённой машине замок неактивен.
- У плагина нет команды CLI, инструмента агента и навыка: охрану открывает только нажатие владельца. Запрет агенту обращаться к RPC плагина обеспечивает хук охраны, а не плагин.
- Значения секретов плагин не читает и не хранит.
