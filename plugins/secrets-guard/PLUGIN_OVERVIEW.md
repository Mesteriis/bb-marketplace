## Что делает

Добавляет замок рядом с кнопкой отправки в поле ввода треда. Нажатие открывает окно, где охрана защищённых файлов Claude Code открывается на 10, 30 или 60 минут: для этого чата, для чата со всеми его субтредами или глобально. Бессрочного открытия нет.

На замке виден остаток времени, подсказка называет охват. Кнопки срока при открытой охране продлевают её, «Закрыть» снимает то открытие, которое действует для треда. В компактной раскладке то же окно открывает строка «Секреты…» в меню «+».

## Как это устроено

Плагин пишет общий файл-отметку, который читает хук охраны Claude Code на том же Mac. Сети между хуком и плагином нет. Фраза владельца «открой секреты» и «закрой секреты» продолжает работать и пишет ту же отметку; запись идёт под файлом-замком и через временный файл.

Для охвата «с субтредами» плагин записывает каждого потомка и обновляет записи, когда тред создаётся, архивируется, удаляется или меняет родителя. Если список субтредов получить не удалось, их записи снимаются до следующей удачной сверки; корневой чат остаётся открыт.

## Настройка

Укажите в настройках плагина полный путь к файлу отметки. Пока поле пусто или каталог файла недоступен для записи, замок неактивен, а охрана остаётся закрытой. При смене пути плагин сначала закрывает всё, что открыто в прежнем файле.

## Ограничения

- Работает только для тредов Claude Code на машине, где запущен сервер BB. У других провайдеров хука охраны нет.
- Для треда на удалённой машине замок неактивен.
- У плагина нет команды CLI, инструмента агента и навыка: охрану открывает только нажатие владельца. Запрет агенту обращаться к RPC плагина обеспечивает хук охраны, а не плагин.
- Значения секретов плагин не читает и не хранит.
