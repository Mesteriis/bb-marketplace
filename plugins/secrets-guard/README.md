# Охрана секретов

Плагин BB: замок у поля ввода треда открывает и закрывает охрану защищённых
файлов Claude Code на 10, 30 или 60 минут — для этого чата, для чата с
субтредами или глобально.

## Окно

- Закрыто: строка «Кому» (сегменты «Этот чат», «С субтредами», «Глобально») и
  «Открыть на» (10, 30, 60 мин). Срок открывает сразу, с выбранным охватом.
- Открыто: «Открыто ещё N мин · охват», кнопка «Закрыть», полоса остатка и та
  же строка с подписью «Продлить на». Полоса показывает долю от 60 минут:
  исходный срок в отметке не хранится.
- Замок у поля ввода: приглушённый, когда закрыто; подсвеченная плашка с
  остатком, когда открыто.
- Замок открывает собственный поповер плагина (`@radix-ui/react-popover`, его
  экземпляр подставляет хост): над кнопкой, по её правому краю, по ширине
  содержимого, в пределах окна. Escape, нажатие вне и повторное нажатие на
  замок закрывают; фокус при открытии уходит в выбранный сегмент охвата, при
  закрытии возвращается на замок. После открытия или закрытия охраны поповер
  остаётся и показывает новое состояние.
- Строка «Секреты…» в меню «+» открывает те же элементы в окне хоста
  (`experimental_popups`); в компактной раскладке, где замка нет, это
  единственный путь. Там раскладка «на всю ширину»: охват растянут, сроки в
  конце строки; в узком окне сроки под охватом, три сегмента в одну строку, а
  подпись остаётся у выбранного (у остальных — значок с названием в подсказке).
- Цвета, радиусы и шрифт берутся из токенов темы BB, значки — из `lucide-react`.

## Настройка

Настраивать ничего не нужно. Хук охраны Claude Code публикует путь к своей
отметке в файле-указателе `~/.claude/hooks/guard-location.json`:

```json
{ "stateFile": "<абсолютный путь к файлу отметки>" }
```

Плагин читает указатель при каждом обращении к отметке, поэтому видит его и
тогда, когда хук создал его уже после старта плагина. Указателя нет, он не
читается, не JSON, `stateFile` не строка или не абсолютный путь — замок
неактивен, охрана закрыта.

Настройка `stateFile` необязательна. Непустая, она переопределяет указатель и
к нему не возвращается, даже если путь в ней неверный. Каталог файла недоступен
для записи — замок неактивен.

Когда путь меняется (в настройке или в указателе), плагин сначала закрывает
всё, что открыто в прежнем файле. Пока указатель не читается, прежний файл не
трогается.

## Формат отметки

```json
{
  "until": 1795800000,
  "threads": {
    "thr_aaa": { "until": 1795800600, "root": "thr_aaa", "tree": true },
    "thr_bbb": { "until": 1795800600, "root": "thr_aaa", "tree": true }
  }
}
```

- `until` — глобальный срок в секундах Unix; нет поля или срок в прошлом — закрыто.
- `threads[<id>]` — срок для треда; `root` — тред, где нажали кнопку; `tree` —
  открыто ли вместе с субтредами.
- Любая ошибка чтения или разбора означает «закрыто».

Писателей двое: плагин и хук фразы владельца. Оба берут замок (путь отметки с
суффиксом `.lock`, ожидание до 2 секунд, замок старше 30 секунд считается
брошенным), пишут через временный файл и переименование и сохраняют чужие поля
верхнего уровня. Каждая запись плагина добавляет строку в журнал рядом с
отметкой (то же имя с расширением `.log`) с пометкой `"by": "plugin"`.
Открытие без строки журнала не выполняется; закрытие от журнала не зависит.
Писатель, чей замок сочли брошенным и забрали, отметку не меняет.

## RPC

- `state({ threadId })` — `{ configured, local, effective }`.
- `open({ threadId, scope, minutes })` — `scope`: `thread`, `tree`, `global`;
  `minutes`: только 10, 30 или 60.
- `close({ threadId })` — закрывает то, что действует для треда.

Отказы: путь не задан, недоступен для записи или занят — `conflict`; тред не
на машине сервера BB — `forbidden`.

У плагина нет команды CLI, инструмента агента и навыка.

## Устройство

- `src/core` — состояние отметки, сбор потомков, сценарии; без кода хоста.
- `src/ui` — подписи, кнопка и окно; данные и действия приходят через props.
- `src/adapters/bb` — файл-отметка, контракт RPC, входы сервера и приложения BB.

## Проверка

```
npm run check

```

## Стенд компонентов

Окно и кнопку можно открыть вне BB, с настоящими компонентами и темой хоста:

```
npm run build
node stand/build.mjs <путь к index-*.css приложения BB>
npx vite preview --outDir dist stand
```

`?theme=dark|light|mock` выбирает тему (mock — палитра макета), `?view=mock|states|popover`
— три раздела макета, все состояния или поле ввода с поповером у замка. На стенде
поповер — копия библиотеки из npm, а не экземпляр хоста.
