# Makosh TreadChat

Отдельный центральный экран существующего треда BB с обзором, диалогом и полем для уточнения. Пакет `bb-plugin-makosh-treadchat`, ID `makosh-treadchat`. Целевые версии для этой сборки — BB **0.50.1**, Plugin SDK **0.6.157**.

## Установка в тестовом BB

Распакуйте архив и перейдите в каталог `treadchat`. Укажите URL и каталог данных **отдельной** установки BB. Команды сборки и установки работают с указанной установкой.

```sh
export BB_SERVER_URL=http://127.0.0.1:57429
export BB_DATA_DIR=/путь/к/отдельному/каталогу-бб
npm ci
npm run check
npm run build
bb plugin install "$PWD" --yes
bb plugin list
```

В существующем треде нажмите **TreadChat** в заголовке. На узком экране действие доступно в меню заголовка. Также можно открыть Makosh TreadChat из навигации BB и выбрать тред слева. В центре переключаются **Обзор** и **Диалог**. Оба используют один черновик TreadChat. Справа находятся вкладки **Состояние** и **Контекст**, которые можно скрыть штатной кнопкой BB.

Для отправки текста доступны кнопка и Cmd+Enter / Ctrl+Enter. Кнопка **Открыть чат BB** возвращает в штатный чат того же треда, где доступны подтверждения, вложения и расширенные параметры отправки.

## Как работает обзор

- На первом открытии плагин показывает значимые записи из последних 60 событий запрашиваемых типов. После этого загружает события по возрастанию последовательности. **Отметить просмотренным** сохраняет отметку до последней записи текущей подборки из максимум 20 элементов. Следующая подборка открывается после отметки. Черновики и отметки хранятся по треду в профиле браузера и на origin этого BB.
- События берутся из BB. В обзоре сообщения агента получают отдельную метку. Для распознанных команд проверок выводится записанный код выхода. Например, код 0 относится к команде целиком. Для одного события можно открыть сохранённый текст, вывод или diff, если он есть. Технический журнал загружает по 30 событий и монтируется при раскрытии.
- Поле ввода фиксирует тред при отправке. Плагин передаёт текст с режимом `steer-if-active` и использует уже выбранные в BB параметры исполнения. Текущие запросы на ответ открываются в штатном чате. В обзоре может отображаться текущий шаг плана провайдера. Полный список шагов раскрывается в штатном представлении.
- После разрыва соединения вкладка сообщает о возможной неактуальности данных и догружает события после восстановления. История остаётся в BB. Сервис суммаризации отсутствует.

## Интеграция

SDK 0.6.157 позволяет открыть отдельный центральный экран через `navPanel`. Слота для подмены содержимого штатного маршрута треда в этой версии SDK нет. Действие в заголовке вызывает `toPluginPanel()` с ID открытого треда. Левый список использует `experimental_useSidebarThreads()`, справа `experimental_tab` добавляет вкладки навигационного экрана.

`ThreadChat` в режиме `timeline` загружается в центре при выборе диалога. Браузерный SDK передаёт сессию BB в `threads.get`, `threads.interactions.list`, `threads.events.list` и `threads.send`. Подписка `thread:changed` и состояние соединения обновляют обзор. Источник запрашивается по порядковому номеру события. Зависимости от Чертога нет.

Сценарий и результаты проверок описаны в [отчёте](QA.md).
