# Makosh TreadChat

Отдельный центральный экран существующего треда BB с обзором, диалогом и полем для уточнения. Пакет `bb-plugin-makosh-treadchat`, ID `makosh-treadchat`. Целевые версии для этой сборки — BB **0.50.1**, Plugin SDK **0.6.157**.

## Установка в тестовом BB

Распакуйте архив и перейдите в каталог `treadchat`. Укажите URL и каталог данных **отдельной** установки BB. Команды сборки и установки работают с указанной установкой.

```sh
export BB_SERVER_URL=http://127.0.0.1:57429
export BB_DATA_DIR=/путь/к/отдельному/каталогу-бб
npm ci
npm run check
npm run build
bb plugin install "$PWD" --yes
bb plugin list
```

В существующем треде нажмите **TreadChat** в заголовке. На узком экране действие доступно в меню заголовка. Также можно открыть Makosh TreadChat из навигации BB и выбрать тред слева. В центре переключаются **Обзор**, **Диалог** и **Технический журнал**. В «Обзоре» центр занимает лента TreadChat. Чтобы написать, откройте «Диалог»: там BB показывает свою переписку и штатное поле с выбором модели, диктовкой, вложениями и меню отправки. Справа находятся вкладки **Состояние** и **Контекст**, в собственной колонке TreadChat. В узком окне эта колонка переносится под диалог. «Состояние» показывает прогресс, явно отмеченные агентом решения, изменённые файлы и последнюю зарегистрированную проверку, если есть такие события. Каждый источник открывается по нажатию.

Кнопка **Открыть чат BB** возвращает в штатный маршрут того же треда. Если сохранился черновик из TreadChat 0.2.0, его можно прочитать и перенести в пустое поле BB. Существующий черновик BB сохраняется.

## Как работает обзор

- На первом открытии плагин показывает значимые записи из последних 60 событий запрашиваемых типов. После этого загружает события по возрастанию последовательности. **Отметить просмотренным** сохраняет отметку до последней записи текущей подборки из максимум 20 элементов. Следующая подборка открывается после отметки. Черновики и отметки хранятся по треду в профиле браузера и на origin этого BB.
- События берутся из BB. В обзоре сообщения агента получают отдельную метку. Для распознанных команд проверок выводится записанный код выхода. Например, код 0 относится к команде целиком. Для одного события можно открыть сохранённый текст, вывод или diff, если он есть. Технический журнал загружает по 30 событий и монтируется при раскрытии.
- Поле ввода и отправку ведёт BB. Черновик BB сохраняется при переходе из «Диалога» в другие режимы и при переключении тредов. В обзоре виден текущий этап провайдера, а справа — шаги и фактический прогресс, если BB получил план.
- После разрыва соединения вкладка сообщает о возможной неактуальности данных и догружает события после восстановления. История остаётся в BB. Сервис суммаризации отсутствует.

## Интеграция

SDK 0.6.157 позволяет открыть отдельный центральный экран через `navPanel`. Слота для подмены содержимого штатного маршрута треда в этой версии SDK нет. Действие в заголовке вызывает `toPluginPanel()` с ID открытого треда. Левый список использует `experimental_useSidebarThreads()`, состояние и контекст справа размещены внутри экрана TreadChat.

Полный штатный компонент `ThreadChat` монтируется только в режиме «Диалог». У «Обзора» и «Технического журнала» свои независимые режимы без штатной ленты и композера. Браузерный SDK передаёт сессию BB в `threads.get`, `threads.interactions.list` и `threads.events.list`. Подписка `thread:changed` и состояние соединения обновляют обзор. Источник запрашивается по порядковому номеру события. Зависимости от Чертога нет.

Сценарий и результаты проверок описаны в [отчёте](QA.md).
